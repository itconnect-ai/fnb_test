# ☕ 프렙 카페 운영 관리 시스템 (Prep Cafe Operations System)

> **서버·구독료 없이 브라우저에서 단독 구동되는 1인 카페 사장님을 위한 올인원 매장 관리 웹 애플리케이션**  
> 메뉴 수익성 분석(공헌이익) • 당월 마감 예상 손익 프로젝션(P&L) • 11개 원부자재 수불 추적 및 거래처 규격 올림 발주서 복사 • 11개 시트 엑셀 백업 및 100% 무결성 복원

---

## 📌 주요 기능 (Core Modules)

### 1. 📊 마감 홈 대시보드 (Closing Home)
* **4대 핵심 KPI 실시간 집계**: 오늘 순매출액, 직접원가율(%), 재고 부족 긴급 발주 건수, 오늘 실질 순수 마진(공헌이익).
* **마감 업무 체크리스트 3단계 루틴**:
  1. 당일 판매 및 재료 입출고 등록 완료
  2. 긴급 부족 재료 거래처 발주 확인 (발주점 ROP 감지 시 경고 뱃지)
  3. 오늘 손익 및 당월 마감 예상 이익 확인 후 일일 마감 확정
* **11개 시트 엑셀 전체 백업 및 복원**: 서버 없이 브라우저 IndexedDB 데이터를 엑셀(`.xlsx`)로 내보내고 완벽하게 복구.

### 2. 📝 일일 마감 판매·지출·입출고 입력 (Closing Input)
* **판매 전표 입력 (매장/포장 분리)**: 판매 수량 및 할인액 입력 시 개당 실질 순마진과 마진율(%) 실시간 프리뷰.
* **원가 역전(역마진) 경고 감지**: 할인액 과다로 마진이 음수가 될 경우 실시간 붉은색 경고 표시.
* **8대 매장 운영비(지출) 등록**: 일일 특이 지출 발생 시 등록 및 삭제 관리.
* **원부자재 입고(+) 및 폐기(-) 등록**: 당일 거래처 입고 및 유통기한 폐기 수량을 등록하여 수불부에 즉시 연쇄 반영.

### 3. 📈 메뉴 수익성 분석 (Menu Profitability)
* **실질 순수 마진(공헌이익) 정밀 연산**: $\text{마진} = \text{판매단가} - \text{식재료비} - \text{포장재비(포장 시)} - \text{결제수수료(1.5\%)}$.
* **단가 이력제(Price History)**: 식재료 가격 인상 시 과거 실적의 원가를 왜곡하지 않고 귀속일자 기준 유효 단가 적용.
* **BCG 매트릭스 4분면 진단 뱃지**:
  * ⭐ **효자(스타)**: 고마진 + 다판매 (예: 아메리카노)
  * 📈 **인기(볼륨)**: 저마진 + 다판매 (예: 카페라떼, 크루아상)
  * 💎 **고수익(틈새)**: 고마진 + 소판매 (예: 말차라떼, 레몬에이드)
  * ⚠️ **재검토**: 저마진 + 소판매 (예: 치즈케이크)

### 4. 📉 예상 손익 및 당월 마감 프로젝션 (Expected P&L)
* **과목별 실적 손익계산서 (P&L)**:
  * 순매출액 - 매출원가(COGS) = 매출총이익
  * 매출총이익 - 판매관리비(수수료 + 8대 일할 운영비) = **영업이익**
* **직전 4주 요일 패턴 기반 당월 마감 예상 손익 프로젝션**:
  * 경과일(1~18일) 실제 실적 + 잔여일(19~30일) 최근 요일별(평일/주말) 평균 가중치 매칭.
  * 이번 달 최종 예상 매출 및 예상 순이익, 전월(MoM) 대비 증감률(%) 제공.
* **손익분기점 (BEP) 분석 게이지**:
  * 고정 운영비 대비 현재 공헌이익 달성률(%) 및 손익분기 초과 안전이익 시각화.

### 5. 📦 재고 수불 및 규격 올림 발주 (Inventory & Order)
* **11개 핵심 원부자재 일별 연속 수불부**:
  * 기초재고 + 입고 - 판매소모(레시피 연동) - 폐기 ± 실사차이 = 당일 마감재고.
  * 과거 판매나 입출고 수정 시 오늘까지의 재고가 **자동 연쇄 재계산(Cascade Update)**.
* **납기일·안전재고 기반 발주점(ROP) 감지**:
  * $\text{ROP} = \text{최근 일평균 소모량} \times (\text{납기일} + \text{안전재고일})$.
* **거래처 구매 규격(pack_quantity) 자동 올림(Ceil) 발주 추천**:
  * 낱개 부족분을 거래처 박스/팩/봉 단위로 자동 올림 계산.
* **원클릭 카카오톡/문자 발주서 복사**:
  * 거래처별로 깔끔하게 정리된 텍스트 양식을 클립보드에 원클릭 복사 (`Ctrl+V`로 전송).

## 🛠️ 기술 스택 (Tech Stack)

* **프레임워크 / 빌더**: [Vite](https://vitejs.dev/) + Vanilla JavaScript (ES Modules)
* **스타일링**: Pure Vanilla CSS (CSS Variables 기반 고밀도 데스크톱 최적화 디자인 시스템)
* **로컬 데이터베이스**: [IndexedDB](https://developer.mozilla.org/ko/docs/Web/API/IndexedDB_API) (브라우저 영구 보존, 11개 객체 스토어)
* **엑셀 엔진**: [SheetJS (xlsx)](https://sheetjs.com/) (11개 시트 전체 백업 및 무결성 복원)
* **배포 환경**: GitHub + Vercel 정적 호스팅 완벽 호환 (별도 백엔드 서버 불필요)

## 🚀 로컬 실행 방법 (Getting Started)

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 구동
```bash
npm run dev
```
브라우저에서 `http://localhost:3000`으로 접속합니다. (기존 445일치 실적 데이터가 자동으로 IndexedDB에 적재됩니다)

### 3. 전체 자동화 테스트 실행
```bash
node test_epic1.js    # EPIC 1: 단가 이력, 마진, 4분면 뱃지 검증
node test_epic2.js    # EPIC 2: 일할 안분, 실적 손익, 당월 예측 검증
node test_epic3.js    # EPIC 3: 수불 연쇄, ROP 규격 발주, 엑셀 백업 검증
node test_e2e_full.js # 전체 통합 E2E 흐름 및 멱등성/안전 차단 검증
```

### 4. 프로덕션 빌드
```bash
npm run build
```

## 🔒 데이터 안전성 및 무결성 (Data Safety)

* **서버리스 로컬 퍼스트**: 외부 유료 API나 서버 장애와 무관하게 매장의 모든 데이터는 브라우저 내부 IndexedDB에 안전하게 암호화 보존됩니다.
* **엑셀 멱등성(Idempotence)**: 동일한 엑셀 백업 파일을 여러 번 업로드해도 판매/재고 레코드가 중복 생성되지 않습니다.
* **오류 차단 및 롤백**: 잘못된 형식의 파일이나 필수 시트가 누락된 파일을 업로드할 경우 즉시 감지하여 차단하며, 기존 데이터는 1원도 유실되지 않고 안전하게 보존됩니다.
