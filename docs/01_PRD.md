> **버전**: v1.0  
> **작성일**: 2026-09-20  
> **작성자**: 기획 담당자  
> **검토자**: 카페 대표 (사장님)

## 1. 문제 (Problem)

### 1.1 배경 및 현재 상황 [확정]
* 카페를 1인 또는 소규모로 운영하면서, POS 장부나 단순 매출 기록만으로는 매장의 실질적인 경영 상태를 종합적으로 파악하기 어렵습니다.
* 특히 다음 4가지 핵심 질문에 대해 직관적인 답을 얻지 못하고 있습니다:
  1. **어떤 메뉴가 잘 팔리고 실제로 많이 남는가?** (단순 매출이 아닌, 식재료비와 포장재비, 카드수수료를 뺀 진짜 이익)
  2. **매장 운영비를 제하고 나면 이번 달 내 손에 쥐는 순이익이 얼마인가?** (임차료, 인건비, 공과금 등을 반영한 영업 손익)
  3. **현재 판매 추세대로 마감하면 이번 달 최종 결과는 어떻게 될 것인가?** (월말 손익 프로젝션 및 목표 달성 여부)
  4. **오늘 밤 어떤 재료가 바닥나고, 내일 배송받으려면 무엇을 몇 팩 주문해야 하는가?** (재고 부족 알림 및 실질적 발주 수량)

### 1.2 목표 [확정]
* 매장 마감 후 사장님이 5~10분만 투자하면 **메뉴 수익성**, **예상 손익**, **재고 및 발주**를 한눈에 파악하고 즉각적인 경영 의사결정을 내릴 수 있는 간결하고 직관적인 통합 관리 프로그램을 구축합니다.

## 2. 사용 흐름 (User Flow)

### 2.1 주 사용자 및 사용 루틴 [확정]
* **주 사용자**: 카페 사장님 1인
* **사용 시점**: **매장 마감 후 (또는 익일 오픈 전)** 하루 1회 집중 사용 (약 5~10분 소요)
* **운영 환경**: 매장 POS/PC 또는 사장님 노트북의 웹 브라우저 환경

### 2.2 일일 마감 사용 여정 (Daily Workflow) [확정]
```
[1. 데이터 입력/업로드] ➔ [2. 오늘 실적 & 발주 확인] ➔ [3. 이번 달 예상 손익 점검] ➔ [4. 저장 및 백업]
 (당일 판매/입고 입력      (오늘의 순익 확인 &            (최근 요일 패턴 기반        (로컬 저장 및 
  또는 엑셀 일괄 등록)       부족 재료 팩단위 발주)         월말 순이익 전망 확인)       필요 시 백업 파일 내보내기)
```

1. **1단계: 마감 데이터 입력/가져오기**
   * 사장님이 프로그램에 접속하여 오늘의 판매 내역(메뉴별 수량, 채널)과 오늘 들어온 재료(입고), 버린 재료(폐기)를 화면에서 간편하게 직접 입력하거나, POS/장부 엑셀 파일을 업로드합니다.
2. **2단계: 오늘 실적 & 긴급 발주 확인 (데일리 대시보드)**
   * 오늘 하루의 **순매출**, **재료비**, **카드수수료**를 차감한 오늘의 1차 마진(공헌이익)을 즉시 확인합니다.
   * 화면 상단 알림 영역에서 **"내일 배송받으려면 오늘 밤 발주해야 할 재료"**와 거래처 규격(원두 N봉, 우유 N팩)으로 계산된 추천 수량을 확인하고 거래처에 주문합니다.
3. **3단계: 이번 달 예상 손익 및 메뉴 성적 분석**
   * 이번 달 현재까지의 누적 손익과 함께, **최근 요일별 판매 패턴을 반영한 '이번 달 최종 예상 순이익'**을 확인하여 남은 기간 운영 전략을 세웁니다.
   * 필요에 따라 메뉴 랭킹 탭을 눌러 어떤 메뉴가 마진율이 높고 효자 노릇을 했는지 점검합니다.
4. **4단계: 주기적 심층 분석 및 데이터 보존 (주간/월간 루틴)**
   * 주말이나 월말에는 기간 필터(주·월·분기·반기·연간)를 변경하여 계절별/분기별 추이를 살펴보고, 정기적으로 **'데이터 백업 파일'**을 다운로드하여 안전하게 보관합니다.

## 3. 필수 기능 (Core Features)

### 3.1 메뉴 수익성 분석 [확정]
* **직접 원가 마진(공헌이익) 산출**:
  $$\text{메뉴 순수 마진} = \text{판매단가} - \text{식재료비} - \text{포장재비(포장 시)} - \text{결제수수료(1.5\%)}$$
  * 매장 공통 고정비(월세, 인건비 등)를 메뉴마다 임의로 나누지 않고, 메뉴 1잔이 순수하게 벌어다 주는 실질 이익을 계산합니다.
* **메뉴별 성적표 및 순위 비교**:
  * 메뉴별 판매 수량, 총매출액, 총 마진액, 마진율(%)을 일·주·월·분기·반기·연간 단위로 정렬하여 표시합니다.
  * '매출 1위 메뉴'와 '실제 마진 1위 메뉴'를 비교하여 프로모션이나 가격 조정의 근거를 제공합니다.
* **매장 vs 포장 채널 분리 분석**:
  * 동일 메뉴라도 매장 판매(다회용 컵 사용, 포장재 0원)와 포장 판매(포장컵/디저트포장세트 소모)를 분리하여 채널별 수익성을 추적합니다.

### 3.2 매장 손익 및 월말 손익 예측 (P&L & Projection) [확정]
* **실질 영업손익 계산 (실적)**:
  $$\text{영업이익} = \text{순매출} - \text{직접원가(식재료+포장재)} - \text{결제수수료} - \text{매장 운영비(일할 배분된 월비용)}$$
  * 8개 운영비 항목(임차료, 직원 급여, 수도광열비, 세무기장료, 통신비 등)을 반영하여 실제 사장님 손에 쥐는 순이익을 산출합니다.
* **최근 요일별 평균 기반 월말 예상 손익 프로젝션 [확정]**:
  * 아직 마감되지 않은 이번 달 잔여 일수에 대해, 평일(월~목)과 주말(금~일)의 **최근 요일별 평균 순매출 실적**을 각각 매칭하여 남은 기간의 매출을 추정합니다.
  * 남은 기간 예상 매출에서 예상 원가 및 잔여 운영비를 차감하여 **"이번 달 최종 예상 매출 및 예상 순이익"**을 신뢰도 높게 제시합니다.
* **기간별 유연한 조회**:
  * 일(Day), 주(Week), 월(Month), 분기(Quarter), 반기(Half-year), 연간(Year) 탭을 통해 매장의 중장기 성장 추세를 확인합니다.

### 3.3 재고 수불 및 패키지 묶음 발주 추천 [확정]
* **연속적 재고 수불 추적**:
  $$\text{오늘 마감 재고} = \text{전일 재고} + \text{입고} - \text{판매 소모량(레시피 기준)} + \text{폐기(음수)} \pm \text{실사조정}$$
  * 판매 데이터와 레시피가 연동되어 자동으로 당일 재료 소모량이 차감됩니다.
* **납기일·안전재고 기반 발주 필요 품목 감지 [확정]**:
  * 재료별 등록된 `납기일(lead_days: 1~2일)`과 `안전재고 일수(safety_days: 1~2일)`를 기준으로, 최근 일평균 소모량 감안 시 배송 기간 내 바닥날 위험이 있는 품목을 자동으로 감지합니다.
* **구매 규격(팩/박스 단위) 자동 올림 발주 추천 [확정]**:
  * 부족 예상 수량을 낱개(g, ml)로 보여주는 것이 아니라, 거래처 공급 단위(원두 1,000g 팩, 우유 1,000ml 팩, 포장컵 100개 세트 등)로 올림(Ceil) 계산하여 사장님이 즉시 주문할 수 있는 실질 수량(예: 우유 12팩, 원두 2봉)을 제시합니다.

### 3.4 데이터 입력·가져오기 및 보존 관리 [확정]
* **화면 직접 입력 및 수정**:
  * 마감 시 판매 수량, 재료 입고 내역, 폐기/실사 내역, 지출 항목을 직관적인 폼에서 간편하게 등록/수정/삭제합니다.
* **엑셀 파일 가져오기 (Import)**:
  * 기존 `매장운영데이터.xlsx`와 동일한 양식의 엑셀 파일을 업로드하여 과거 기록이나 누적 데이터를 한 번에 가져옵니다.
* **데이터 로컬 저장, 백업 및 복원 (Export / Restore)**:
  * 입력된 모든 매장 운영 데이터는 브라우저/로컬 환경에 영구 저장됩니다.
  * 사장님이 원할 때 언제든 전체 데이터를 안전한 단일 백업 파일(JSON 또는 엑셀)로 다운로드(내보내기)할 수 있습니다.
  * PC 변경이나 브라우저 초기화 시 백업 파일을 업로드하여 기존 데이터를 100% 복원할 수 있습니다.

## 4. 제외 범위 (Out of Scope) [확정]

* **거래처 자동 주문/발주 전송**:
  * 시스템이 식자재몰이나 거래처에 직접 주문을 넣거나 결제를 실행하지 않습니다. 시스템은 최적의 '추천 발주서'를 화면에 띄워주고, 실제 주문(전화, 문자, 발주앱 입력)은 사장님이 직접 실행합니다.
* **PG 결제 승인 및 카드 매출 자동 정산 연동**:
  * 외부 결제대행사(PG)나 여신금융협회 API와 실시간 통신하여 카드 승인/입금을 자동 처리하는 금융 연동 기능은 포함하지 않습니다.
* **POS 및 배달 플랫폼(배민/쿠팡이츠 등) 무인 실시간 API 연동**:
  * 복잡하고 불안정한 외부 유상 API 대신, 사장님이 일일 마감 시 엑셀을 업로드하거나 직접 합산 숫자를 입력하는 직관적이고 안정적인 방식을 채택합니다.

## 5. 완료 조건 (Definition of Done)

### 5.1 기획 완료 조건 (현재 단계) [확정]
1. [x] 사장님의 핵심 요구사항(누가, 언제, 어떤 판단을 내리는지)이 모두 질문을 통해 구체화됨.
2. [x] 메뉴 수익성, 예상 손익, 재고 발주 추천의 핵심 계산 기준이 명확히 정의됨.
3. [x] 본 PRD 문서(`docs/01_PRD.md`)에 대해 **사장님의 최종 검토 및 승인**을 획득함.

### 5.2 개발 완료 조건 (향후 구현 단계) [확정]
1. **데이터 검증**: 기존 `data/` 폴더의 매장 데이터(445일치 실적 및 마스터 정보)를 완벽하게 불러와 기존 지표와 오차 없이 표시되어야 함.
2. **핵심 3대 대시보드 구현**:
   - 메뉴 수익성: 마진율 순위, 식재료/포장비/수수료 분해, 채널별 마진 확인 가능.
   - 손익 및 예측: 기간별 실적 손익 집계 + 최근 요일 패턴 기반 당월 마감 예상 손익 표시.
   - 재고 및 발주: 11개 재료의 일별 수불부 추적 + 납기/안전재고 기반 팩 단위 발주 추천 목록 표시.
3. **사용성 및 데이터 안전성**:
   - 마감 후 5~10분 내에 일일 입력 완료가 가능한 직관적인 UI 제공.
   - 엑셀 업로드 정상 작동 및 전체 데이터 백업 파일 생성/복원 기능 정상 작동.

## 6. 추가 확인 사항 및 최종 확정 내용 [확정]

사장님 피드백을 통해 다음 2가지 사항이 최종 확정되었습니다:

1. **기존 과거 데이터 적재 여부 [확정]**:
   - **바로 볼 수 있는 상태로 시작**: 프로그램을 켰을 때 `data/` 폴더에 있는 **기존 445일치 매장 운영 데이터(2025.07~2026.09)**가 기본으로 적재되어, 사장님이 첫 실행 즉시 풍부한 메뉴 순위와 손익 통계, 재고 수불 그래프를 바로 조회하고 활용할 수 있도록 합니다.
2. **백업 파일 저장 형식 [확정]**:
   - **엑셀 파일(.xlsx) 중심 지원**: 사장님이 엑셀로 직접 열어보고 관리하기 가장 편하시도록 전체 데이터 백업 및 복원은 **엑셀 파일(.xlsx)** 형식을 표준으로 지원합니다. (보조적으로 시스템 완전 복원용 JSON도 함께 지원)
